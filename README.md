# OOP Innovative Assignment - Problem C

## Problem Statement
Create a custom exception called InvalidSpeciesException.
Throw the exception when the species name is left empty.

## Description
This Java program asks the user to enter a species name.
If the species name is empty, the program throws and catches
InvalidSpeciesException.
Otherwise, it displays the species name.

## Sample Output

Enter species name: Lion
Species: Lion

For empty input:

Enter species name:
Species name cannot be empty
